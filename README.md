# 🐍 Fundamentos de Linguagem Python - Do Básico a Aplicações de IA

Repositório com anotações, exercícios e projetos desenvolvidos durante o curso **"Fundamentos de Linguagem Python - Do Básico a Aplicações de IA"**, oferecido gratuitamente pela [Data Science Academy (DSA)](https://www.datascienceacademy.com.br/).

## 📌 Sobre o Curso

Trilha de aprendizado completa que leva o aluno do zero absoluto em programação até a criação de soluções de Inteligência Artificial. Estruturado em uma jornada lógica e progressiva, o curso une teoria e prática por meio de **10 mini-projetos reais**, simulando desafios do dia a dia de um profissional de dados e IA — da lógica de programação básica até IA Generativa, LLMs e agentes autônomos.

## 🎯 O Que Este Curso Aborda

- Fundamentos da linguagem Python (sintaxe, lógica de programação, estruturas de dados)
- Programação Orientada a Objetos (POO)
- Ciência de Dados com **NumPy**, **Pandas** e **Statsmodels**
- Machine Learning para modelagem preditiva (ex: previsão de sentimentos)
- Aplicações interativas e dashboards com **Streamlit**
- **MLOps** na prática
- Redes neurais com **PyTorch** para classificação de imagens
- IA Generativa: **LLMs** e **RAG** (Retrieval-Augmented Generation)
- Desenvolvimento de **agentes autônomos** para automação

## 🛠️ Tecnologias e Ferramentas

- **Python 3.x**
- **NumPy** e **Pandas**
- **Statsmodels**
- **Scikit-learn** (Machine Learning)
- **PyTorch** (Deep Learning)
- **Streamlit** (aplicações interativas)
- **LLMs e RAG** (IA Generativa)
- **Jupyter Notebook** / **Google Colab**

## 📈 Mini-Projetos Práticos

O curso é construído em torno de 10 mini-projetos práticos, incluindo:

- 🎮 **Game em Python** — lógica de programação aplicada
- 🏦 **Sistema Bancário com POO** — Programação Orientada a Objetos
- 🛒 **Análise de Dados de E-commerce** — NumPy e Pandas
- 🤖 **Modelo de Machine Learning para Previsão de Sentimentos**
- 📊 **Aplicação Interativa com Streamlit**
- 🧠 **Rede Neural com PyTorch** — classificação de imagens
- 💬 **Assistente de IA para Programação**
- 🔍 **Solução de IA Generativa com LLMs e RAG**
- 🕵️ **Agente Autônomo para Automação**
