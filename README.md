# Fundamentos_Python_DSA
Este repositório contém os códigos e materiais relacionados ao curso de Fundamentos de Python para Data Science e Análise de Dados. O curso abrange os conceitos básicos de Python, estruturas de dados, manipulação de dados, visualização e outras habilidades essenciais para quem deseja trabalhar com dados.

## Conteúdo
- Introdução ao Python, com criação de um agente de IA usando pytohn e groq
- Estruturas de dados em Python (listas, tuplas, dicionários, conjuntos)
- Manipulação de dados com pandas
- Visualização de dados com matplotlib e seaborn
- Fundamentos de programação orientada a objetos
- Boas práticas de codificação e organização de projetos
